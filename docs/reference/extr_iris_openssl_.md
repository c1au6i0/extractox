# extr_iris_openssl\_

extr_iris_openssl\_

## Usage

``` r
extr_iris_openssl_(
  casrn,
  cancer_types = c("non_cancer", "cancer"),
  verbose = TRUE
)
```

## Arguments

- casrn:

  A vector CASRN for the search.

- verbose:

  A logical value indicating whether to print detailed messages. Default
  is TRUE.
