# Extract Assay Names from the ICE Database

This function allows users to search for assay names in the ICE database
using a regular expression. If no search pattern is provided
(`regex = NULL`), it returns all available assay names.

## Usage

``` r
extr_ice_assay_names(regex = NULL, verbose = TRUE)
```

## Arguments

- regex:

  A character string containing the regular expression to search for, or
  `NULL` to retrieve all assay names.

- verbose:

  A logical value indicating whether to print detailed messages. Default
  is TRUE.

## Value

A character vector of matching assay names.
